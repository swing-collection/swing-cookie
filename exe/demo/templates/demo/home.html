API Endpoints

The following API endpoints are available:

GET  /status/       - Get current consent status
POST /accept/       - Accept all cookie groups
POST /accept/{var}/ - Accept specific cookie group
POST /decline/      - Decline all cookie groups
POST /decline/{var}/- Decline specific cookie group
POST /preferences/  - Update preferences (JSON body)
POST /withdraw/     - Withdraw all consent
GET  /export/       - Export consent records (GDPR)
